## Getting Started

### For Development

```bash
cd execute
uv sync                    # Install dependencies
uv run pytest              # Run tests
uv run python -m notion_markdown_extractor extract <url>  # Test locally
```

### For Users

```bash
# Install globally
cd execute && uv tool install .

# Configure
notion-md configure --token <your-token>

# Extract pages
notion-md extract "https://notion.so/Your-Page-abc123"
```
